# Context

Shared vocabulary for this site. Definitions only — no implementation
details, no plans.

## Note

A single short entry, listed under Notes. Written by hand, one file per
entry. A Note always has exactly one Note Language.

## Slug

The stable identifier for a Note. It is unique across the whole site: no
two Notes share one, whatever language they are written in. The Slug is
part of the URL and must not change once a Note is published.

## Note Language

The language a Note is written in. It is a property of the article, not
of the site: the interface is English and is never translated. Every
Note appears in the same listing and the same feed regardless of its
Note Language, and nothing on the page announces it — a reader tells
from the title.

## Draft

A Note that is not ready to be read. Drafts are visible while writing
and absent everywhere else — they do not appear in listings, feeds, or
at their own URL once published to the live site.

## Fixture

A Note that exists only to exercise rendering. It is never committed and
never published; it is a development tool that happens to be shaped like
a Note.
